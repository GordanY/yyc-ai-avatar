07 / Rules vs generation

換個問題，看看怎樣回應。

比較「固定規則式聊天機器人」與「LLM 角色」如何處理提問。

RULE-BASED · 固定腳本示例

先寫好規則，再配對答案。

你好，歡迎使用。請輸入關鍵字：「生平」或「事蹟」。

按預設關鍵字及流程回覆；遇到規則以外的問法，這個示例便無法配對。

LLM-BASED · 岳飛角色示例

結合設定與語境，生成回應。

你好，我是以岳飛為藍本的歷史學習角色。你想談談歷史，還是學習上的挑戰？

回覆較靈活，也可能出錯。一次聊天不等於模型被重新訓練，外觀也不會保證史實正確。

09 / Research with Perplexity

資料蒐集工具

先調查岳飛，
再建立他的世界。

Perplexity 是結合搜尋與 AI 回答的研究工具。從一個清楚的問題開始，追查回答中的來源，再整理成你的人物資料。

  1. 複製右方提示指定人物、200–300 字範圍與輸出格式。
  2. 在 Perplexity 貼上並搜尋開啟回答附上的來源，閱讀原文。
  3. 整理人物背景核對摘要是否為 200–300 字；超出時再要求精簡，閱讀來源後整理成背景知識。
開啟 Perplexity ↗
岳飛 · 200–300 字背景摘要繁體中文
我是一名中學生，正在製作以「岳飛」為藍本的歷史學習數字人。請搜尋可靠資料後，只交付一段可直接貼入平台的精簡背景摘要。 【必須遵守】 1. 摘要正文必須是 200–300 字的繁體中文，以 230–260 字為目標。少於 200 字或超過 300 字都不合格，必須修改後才輸出。 2. 正文只能有一個段落。不要分項、列表、表格、前言、結語、完整人物報告、額外分析或建議追問。 3. 精簡涵蓋岳飛的生卒年份、南宋將領身分、宋金交戰背景、主要事蹟及歷史地位。只保留最重要的資訊；不能把後世傳說或文學情節當作已確認史實。 4. 使用第三人稱客觀敘述，不要扮演岳飛。無法確認的細節請刪除或簡短註明。 5. 優先查閱博物館、學術或其他可靠機構的資料。資料來源另列於摘要之後，只提供 2–3 個「機構名稱＋來源連結」，不要逐條介紹來源。 【輸出前自行檢查，不要顯示檢查過程】 計算摘要正文的字數：漢字、英文字母及數字各算一字；不計標點、空白、標題、引用標記及資料來源。若不在 200–300 字內，先自行增刪至合格，再輸出。不要另外顯示字數或解釋。 【只准使用以下輸出格式】 背景摘要 （一個 200–300 字的繁體中文段落） 資料來源 1. 機構名稱：來源連結 2. 機構名稱：來源連結 （如有必要，最多增加第 3 個來源；不要輸出此括號內的提示。）

12 / Your learning journey

認識 → 調查 → 整理 → 製作。

跟着活動流程，把好奇變成一個有內容、可測試的作品。

理解原理

STEP 02 · Perplexity 調查

蒐集人物資料

先連接，再對話。按平台右上角「連接AI model」，在彈出視窗輸入 OpenRouter API 金鑰，按「連接」，等待驗證成功。金鑰只留在該頁記憶體，重新載入須再輸入。

記得比較，也記得查證。每次輸入上限為 200 字／詞，每分頁課堂提問上限為 50 次。更新角色會清空對話，提問次數會保留。重要史實請查證來源。
