歡迎

歡迎來到數字人製作

親手設定一位 人工智能學習伙伴，看看你的選擇如何改變它的回答。

  1. 設定角色填寫名稱與描述，選擇個性和說話語氣，再按「更新數字人」。
  2. 加入知識貼上背景資料，並選擇角色外觀。
  3. 對話與比較輸入 API 金鑰 後開始聊天；修改並更新數字人，再用相同問題比較回答。

更新數字人時會清空對話，但不會重設提問次數。你也可以先用示範回應體驗。
